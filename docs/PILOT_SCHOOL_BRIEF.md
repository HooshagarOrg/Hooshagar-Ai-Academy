این صفحه می‌گوید **چه چیزی الان واقعی است** و **چه چیزی با برچسب «به‌زودی» دیده می‌شود**. قابلیت‌ها مخفی نمی‌شوند؛ دادهٔ نمونه نشان داده نمی‌شود.

## ✅ الان واقعی و قابل استفاده است

| نقش | چه کاری می‌توانید بکنید |
|-----|-------------------------|
| **ورود** | ایمیل/رمز، OTP پیامکی، خروج |
| **ادمین** | مدارس، کاربران، واردسازی گروهی، ارتقاء پایه، انتقال، قرعه‌کشی، نظرسنجی، گزارش، اعلان گروهی داخلی، محدودیت و تست AI، کلاس مجازی (اسکای‌روم) |
| **معلم** | کلاس، حضور، نمرات، رفتار، گزارش هفتگی، آزمون، بانک سوال، تولید محتوا (AI)، آزمون‌ساز، سوالات شفاهی، تحلیلگر، پیام به والدین، کلاس مجازی |
| **والد** | نمرات، گزارش‌ها، حضور، بهداشت، گزارش تخصصی، مشاوره، ثبت‌نام کلاس، نظرسنجی، اعلانات، کلاس مجازی |
| **دانش‌آموز** | نمرات، مسیر یادگیری، آزمون، دستیار مطالعه، حل مسئله (OCR)، استریک، باغ استعداد، نشان، فروشگاه، ثبت‌نام/قرعه‌کشی کلاس، کلاس مجازی |
| **پیام و اعلان** | گفتگوی درون‌برنامه بین کاربران همان مدرسه؛ زنگولهٔ اعلان |
| **فایل** | آپلود در فضای ابری (آروان) |

همهٔ این‌ها به دادهٔ واردشده وابسته‌اند. اگر هنوز دانش‌آموز یا کلاس وارد نشده، صفحه خالی است — نه پر از اسم نمونه.

## 🔶 در منو هست؛ با برچسب «به‌زودی» — مبنای کار روزانه قرار ندهید

| بخش | توضیح |
|-----|--------|
| **امور مالی والدین** | نیاز به اتصال حسابداری مدرسه؛ مبلغ نمونه نشان داده نمی‌شود |
| **معلم:** ارزیابی مهارت پایه، اعطای نشان | هنوز به پایگاه وصل نیست |
| **دانش‌آموز:** راهنمای AI، نقشه راه کنکور، قطب‌نما، زمین بازی | هنوز به دادهٔ واقعی وصل نیست |
| **ادمین:** مدل‌های AI، اعتبار AI، مصرف AI، هشدار زودهنگام، قابلیت‌ها، شهریه | در منو با برچسب |
| **مشاور** | «این نقش هنوز فعال نیست» |
| **مدیر مدرسه، معاونت‌ها، هنر، ورزش، منشی، کتابدار، نگهبان، تأسیسات** | «این نقش هنوز فعال نیست» — برای کار روزمره لازم نیست |

پیامک گروهی / مالی / حضور عمداً خاموش است.

## محدودیت‌های مهم

1. **سهمیه AI:** هر نقش سقف روزانه دارد؛ با اتمام، پیام فارسی می‌آید.
2. **OTP:** وابسته به اعتبار پیامک کاوه‌نگار است.
3. **بک‌آپ:** روزانه ذخیره می‌شود؛ بازیابی فقط توسط تیم فنی (نه از پنل ادمین).
4. **مقیاس:** برای یک مدرسه؛ نه چندصد مدرسه هم‌زمان.
5. **Supabase Pro:** خریداری شده.
