# هوشاگر — راهنمای پایلوت برای مدیر مدرسه

**آدرس:** https://www.hooshagar.ir  
**نسخه:** پایلوت مدرسه‌ای — شهریور ۱۴۰۵  
**پشتیبانی:** info@hooshagar.ir

این سند یک‌صفحه‌ای است تا مدیر مدرسه بداند **چه چیزهایی الان واقعی‌اند** و **چه چیزهایی هنوز نمایشی یا در حال تکمیل‌اند**.

---

## ✅ الان واقعی و قابل استفاده است

| بخش | چه کاری می‌توانید بکنید |
|-----|-------------------------|
| **ورود و امنیت** | ورود با ایمیل/رمز، OTP پیامکی، خروج، محدودیت تلاش اشتباه |
| **نقش‌ها** | ادمین، معلم، والد، دانش‌آموز، مشاور — هر کس فقط به بخش خودش |
| **مدیریت کاربران** | ساخت کاربر، تخصیص مدرسه/کلاس، واردسازی گروهی، قرعه‌کشی |
| **داشبوردها** | داشبورد هر نقش با دادهٔ واقعی از پایگاه داده (در حد دادهٔ واردشده) |
| **هوش مصنوعی دانش‌آموز** | دستیار مطالعه، حل مسئله (OCR)، ابزارهای AI با سهمیهٔ روزانه |
| **اعلان درون‌برنامه** | زنگوله اعلان و صفحهٔ اعلانات |
| **گزارش والدین** | وقتی ادمین گزارش تولید و منتشر کند |
| **آپلود فایل** | ذخیره در فضای ابری (آروان) |
| **موبایل و فارسی** | راست‌چین، قابل استفاده روی موبایل |

---

## 🔶 نمایشی است — برای کار عملیاتی به آن تکیه نکنید

| بخش | توضیح برای مدرسه |
|-----|------------------|
| **امور مالی والدین** | اعداد نمونه‌اند؛ مبنای پرداخت یا بدهی نیست. تا اتصال سامانهٔ مالی واقعی. |
| **پیام‌رسانی درون‌برنامه** | از منوی اصلی مخفی است؛ در صورت دسترسی مستقیم، نمایشی است و به سرور وصل نیست. |
| **تولید محتوا (AI) معلم** | ظاهر کامل دارد ولی خروجی شبیه‌سازی است؛ هنوز به AI واقعی وصل نشده. |
| **برخی صفحات معلم/والد** | رفتار، گزارش هفتگی، مشاوره و… ممکن است دادهٔ نمونه داشته باشند. |
| **صفحات معاونت‌ها** | با برچسب «پایلوت — به‌زودی» — فعلاً برای کار روزمره لازم نیست. |

## ⏳ به‌زودی / بعد از جمع‌آوری بازخورد

| بخش | زمان‌بندی پیشنهادی |
|-----|-------------------|
| **ارتقای زیرساخت (Supabase Pro)** | بعد از شروع استفادهٔ واقعی و جمع شدن داده |
| **اتصال مالی واقعی** | پس از تعیین فرایند شهریه مدرسه |
| **پیام‌رسانی واقعی** | پس از تست داخلی |
| **تولید محتوا AI معلم** | اولویت فنی بعد از معرفی |
| **کلاس مجازی (Skyroom)** | فقط اگر مدرسه بخواهد |
| **پیامک انبوه / مالی / حضور** | عمداً خاموش — فعال‌سازی با هماهنگی |

---

## محدودیت‌های مهم (شفاف)

1. **سهمیه AI:** هر نقش سقف روزانه دارد؛ در صورت اتمام، پیام فارسی نمایش داده می‌شود.
2. **OTP:** به اعتبار پیامک کاوه‌نگار وابسته است.
3. **بک‌آپ:** روزانه در فضای ابری ذخیره می‌شود؛ بازیابی فقط توسط تیم فنی (نه از پنل ادمین).
4. **مقیاس:** برای یک مدرسه طراحی شده؛ نه چندصد مدرسه هم‌زمان.
