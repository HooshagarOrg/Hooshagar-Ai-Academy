## ✅ الان واقعی و قابل استفاده است

| بخش | چه کاری می‌توانید بکنید |
|-----|-------------------------|
| **ورود و امنیت** | ورود با ایمیل/رمز، OTP پیامکی، خروج، محدودیت تلاش اشتباه |
| **نقش‌ها** | ادمین، معلم، والد، دانش‌آموز، مشاور — هر کس فقط به بخش خودش |
| **مدیریت کاربران** | ساخت کاربر، تخصیص مدرسه/کلاس، واردسازی گروهی، قرعه‌کشی |
| **داشبوردها** | داشبورد هر نقش با دادهٔ واقعی از پایگاه داده (در حد دادهٔ واردشده) |
| **هوش مصنوعی دانش‌آموز** | دستیار مطالعه، حل مسئله (OCR)، ابزارهای AI با سهمیهٔ روزانه |
| **تولید محتوا (AI) معلم** | طرح درس، سوال آزمون، ایدهٔ فعالیت — با AI واقعی و سهمیه |
| **پیام‌رسانی درون‌برنامه** | گفتگو و ارسال واقعی بین کاربران همان مدرسه |
| **اعلان درون‌برنامه** | زنگوله اعلان و صفحهٔ اعلانات |
| **گزارش والدین** | وقتی ادمین گزارش تولید و منتشر کند |
| **آپلود فایل** | ذخیره در فضای ابری (آروان) |
| **موبایل و فارسی** | راست‌چین، قابل استفاده روی موبایل |

## محدودیت‌های مهم (شفاف)

1. **سهمیه AI:** هر نقش سقف روزانه دارد؛ در صورت اتمام، پیام فارسی نمایش داده می‌شود.
2. **OTP:** به اعتبار پیامک کاوه‌نگار وابسته است.
3. **بک‌آپ:** روزانه در فضای ابری ذخیره می‌شود؛ بازیابی فقط توسط تیم فنی (نه از پنل ادمین).
4. **مقیاس:** برای یک مدرسه طراحی شده؛ نه چندصد مدرسه هم‌زمان.
