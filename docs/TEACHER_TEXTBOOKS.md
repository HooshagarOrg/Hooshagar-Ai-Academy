# کتاب‌های درسی و تخته تدریس معلمان

## خلاصه

ابزار تدریس داخل‌برنامه (بدون اسکای‌روم):

1. **کتاب‌های درسی PDF** — فایل در آروان؛ فقط metadata در Supabase
2. **تدریس روی PDF** — نقاشی موقت روی کتاب (ذخیره نمی‌شود)
3. **تخته سفید** — بوم خالی با قلم / رنگ / پاک‌کن (بدون ذخیره سرور)

دو قفسه وجود دارد:

- **سراسری** (`school_id` خالی) — ادمین کل برای هر پایه یک‌بار آپلود می‌کند؛ معلمان همان پایه در همه مدارس همان فایل را می‌بینند و مجبور به آپلود مجدد نیستند.
- **مدرسه** (`school_id` پر) — کتاب اضافهٔ همان مدرسه؛ معلمان همان پایه می‌توانند در صورت نیاز آپلود کنند.

## دسترسی

- ادمین کل (`platform_admin` / `admin`): آپلود و حذف قفسه سراسری از `/admin/textbooks`.
- معلمان (`teacher` / `art_teacher` / `sports_teacher`) کتاب‌های **سراسری همان پایه** و کتاب‌های **مدرسه خود** را می‌بینند. حذف کتاب سراسری برای معلم ممکن نیست.
- چند معلم همان پایه همان فایل‌های سراسری را می‌بینند (یک آپلود ادمین برای همه مدارس).
- مدیر مدرسه: همه پایه‌های مدرسه + مشاهده قفسه سراسری؛ حذف سراسری فقط برای ادمین کل.

## مسیرهای UI

| مسیر | توضیح |
|------|--------|
| `/admin/textbooks` | قفسه سراسری: آپلود PDF هر پایه |
| `/teacher/textbooks` | فهرست سراسری + مدرسه؛ آپلود اضافهٔ مدرسه |
| `/teacher/textbooks/[id]` | PDF + لایه نقاشی موقت |
| `/teacher/whiteboard` | تخته سفید خالی |

## API

| متد | مسیر | کار |
|-----|------|-----|
| GET | `/api/teacher/textbooks` | فهرست مدرسه + سراسری (+ پایه‌های مجاز) |
| GET | `/api/teacher/textbooks?scope=platform` | فقط قفسه سراسری (ادمین کل) |
| POST | `/api/teacher/textbooks/presign` | لینک PUT امضا‌شده به آروان؛ `scope: "platform"` برای سراسری |
| POST | `/api/teacher/textbooks` | تأیید آپلود و ثبت ردیف؛ `scope: "platform"` برای سراسری |
| GET | `/api/teacher/textbooks/[id]` | metadata (+ signed URL اختیاری) |
| GET | `/api/teacher/textbooks/[id]/file` | پروکسی PDF same-origin برای iframe |
| DELETE | `/api/teacher/textbooks/[id]` | حذف DB + فایل آروان؛ سراسری فقط ادمین کل |

نمایش داخل iframe با لینک مستقیم آروان معمولاً بلاک می‌شود؛ به همین دلیل viewer از مسیر `/file` روی دامنهٔ اپ استفاده می‌کند.

آپلود مستقیم از مرورگر به آروان است (حداکثر ۵۰MB) تا محدودیت body سایز Vercel دور زده شود.

مسیر فایل سراسری: `textbooks/platform/grade-{n}/...`

## CORS آروان (الزامی برای آپلود)

روی باکت S3 آروان، CORS را طوری تنظیم کنید که دامنهٔ اپ بتواند `PUT` بزند، مثلاً:

- Allowed Origins: `https://www.hooshagar.ir` و `http://localhost:3000`
- Allowed Methods: `GET`, `PUT`, `HEAD`
- Allowed Headers: `*`
- Expose Headers: `ETag`

بدون CORS، مرحلهٔ PUT از مرورگر شکست می‌خورد.

## هزینه

- ذخیره و دانلود CDN آروان (کش مرورگر کمک می‌کند)
- بدون AI و بدون ذخیره blob در Postgres
- یادداشت روی PDF/تخته فقط در حافظه مرورگر است

## قفل پایلوت (عمداً این‌طور می‌ماند)

- لایهٔ نقاشی روی PDF **موقت** است و ذخیره نمی‌شود.
- فایل PDF مرجع در آروان **بازنویسی نمی‌شود**؛ نوشتن روی کتاب یعنی لایهٔ مرورگر، نه تغییر فایل اصلی.
- قفسه سراسری را ادمین کل پر می‌کند تا معلمان همان پایه دوباره آپلود نکنند؛ کتاب اضافهٔ مدرسه همچنان مجاز است.
