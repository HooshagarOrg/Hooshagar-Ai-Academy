# الگوهای پیامک کاوه‌نگار — هوشاگر

**نوع استفاده برای همهٔ الگوهای production:** `وب سایت`  
(نه «تست فنی»، نه «سایر» — مگر واقعاً فقط تست موقت باشد.)

| فیلد فرم | مقدار پیشنهادی |
|----------|----------------|
| نام سامانه | `هوشاگر` |
| لینک سامانه | `https://www.hooshagar.ir` |
| نوع ارسال پیام | `پیامک` |
| ارسال مجدد با مسیر جایگزین | فعلاً غیرفعال |

> متغیرها فقط با `%token` / `%token2` / …  
> برای متن دارای فاصله (نام کامل) از `%token10` یا `%token20` استفاده کنید.  
> نام الگو باید **دقیقاً** با env یکی باشد (انگلیسی، بدون فاصله).

---

## ۱) ضروری الان — OTP ورود

| | |
|--|--|
| **نام الگو** | `otp-login` |
| **env** | `KAVENEGAR_TEMPLATE_OTP=otp-login` |
| **استفاده در کد** | `verify/lookup` در ارسال OTP |

**متن الگو:**
```
کد ورود شما به سامانه هوشاگر: %token%
این کد محرمانه است.
```

- `%token` = کد ۶ رقمی (بدون فاصله)

## ۳) نتیجه قرعه‌کشی

| | |
|--|--|
| **نام الگو** | `lottery-result` |
| **env** | `KAVENEGAR_TEMPLATE_LOTTERY=lottery-result` |
| **وضعیت کد** | فعلاً پیامک آزاد (`sms/send`)؛ الگو برای تأیید کاوه‌نگار / مهاجرت بعدی Lookup |

**متن الگو (پذیرش):**
```
هوشاگر
%token10% عزیز، در کلاس %token% پذیرفته شدید.
مدرسه: %token2%
```

- `%token10` = نام دانش‌آموز  
- `%token` = نام کلاس (بدون فاصلهٔ مشکل‌ساز؛ در صورت نیاز کوتاه کنید)  
- `%token2` = نام مدرسه  

**متن جایگزین (رد):** اگر کاوه‌نگار یک الگو برای هر دو حالت نمی‌پذیرد، الگوی دوم بسازید:

| نام الگو | `lottery-rejected` |
|----------|-------------------|

```
هوشاگر
%token10% عزیز، متأسفانه در قرعه‌کشی این دوره پذیرفته نشدید.
با مدرسه تماس بگیرید.
```

> الگوی فعلی `lottery-result` را ویرایش کنید: نام سامانه **هوشاگر**، لینک **`.ir`**, نوع استفاده **وب سایت**, و `{student}` را با `%token…` عوض کنید.

## ۷) پشتیبانی — زنگ اپراتور و اطلاع رفع به کاربر

کد اگر الگوی Lookup تنظیم نشده باشد، همان متن را با `sms/send` می‌فرستد تا کار قطع نشود. پس از تأیید الگو در پنل، env را پر کنید.

| | |
|--|--|
| **نام الگو** | `support-new` |
| **env** | `KAVENEGAR_TEMPLATE_SUPPORT_NEW=support-new` |
| **گیرنده** | شمارهٔ اپراتور (`SUPPORT_OPERATOR_PHONE`) |
| **چه وقت** | گزارش ورود/حساب یا راهنما ثبت شد |

**متن الگو:**
```
هوشاگر
پشتیبانی جدید: %token%
گزارش‌دهنده: %token10%
مدرسه: %token20%
```

- `%token` = `hesab` یا `rahnama` یا `bag` (بدون فاصله)
- `%token10` = نام کوچک گزارش‌دهنده
- `%token20` = نام مدرسه

| | |
|--|--|
| **نام الگو** | `support-resolved` |
| **env** | `KAVENEGAR_TEMPLATE_SUPPORT_RESOLVED=support-resolved` |
| **گیرنده** | موبایل کاربر در پروفایل |
| **چه وقت** | ادمین در صندوق پشتیبانی «حل شد» می‌زند |

**متن الگو:**
```
هوشاگر
%token10% عزیز، گزارش پشتیبانی شما بررسی و برطرف شد.
www.hooshagar.ir
```

- `%token` = مقدار ثابت `ok` (الزام Lookup کاوه‌نگار)
- `%token10` = نام کوچک کاربر

**نمونهٔ متن آزاد (تا وقتی الگو تأیید نشده):**

اپراتور:
```
هوشاگر: درخواست پشتیبانی جدید (حساب) از علی. مدرسه: نمونه. صندوق ادمین را ببینید.
```

کاربر پس از رفع:
```
هوشاگر: علی عزیز، گزارش پشتیبانی شما بررسی و برطرف شد. www.hooshagar.ir
```

رمز عبور و متن کامل گزارش در پیامک نیست. جزئیات فقط در صندوق داخل برنامه است.

---

## اولویت ثبت در پنل

1. `otp-login` ← بدون این ورود با پیامک کار نمی‌کند  
2. اصلاح `lottery-result`  
3. `support-resolved` و `support-new` (اطلاع رفع به کاربر و زنگ اپراتور)  
4. `attendance-notification` (برای آینده)  
5. بقیه در صورت نیاز

پس از تأیید، در Vercel مقدار envها را با **نام دقیق** الگوها چک کنید (الان با `.env.local` هم‌خوان است).
